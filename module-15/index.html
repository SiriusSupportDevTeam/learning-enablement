Frame 02

The Minimum Necessary Principle

Before entering anything into an AI system, ask: "What is the minimum information needed for AI to perform this task?" Strip every frame that doesn't answer yes.

DETAIL Customer's Name NOT NEEDED
DETAIL Order Number NOT NEEDED
DETAIL Home Address NOT NEEDED

And if a screenshot contains information you don't need — don't upload it, unless your approved process specifically permits it.

Frame 03

Anonymization Workshop

Anonymization means removing or replacing identifying information before a task starts — like swapping a live actor for a stand-in. The scene still works; the identity doesn't leave the trailer. Tap a card to see the retake.

Original Shot

"Sarah Johnson from 18 Jalan ABC ordered SKU 12345 and wants to know if it's eligible for exchange."

Anonymized Retake

"A customer purchased Product A and is asking whether it qualifies for replacement."

Original Shot

"Order #983745 belongs to Michael Tan — his shipment hasn't moved in 6 days and he's furious."

Anonymized Retake

"The customer has an order that is currently delayed."

The goal isn't to erase the story — it's to keep what AI actually needs while cutting unnecessary exposure.

The Prop Closet

CRITICAL RULE

Never paste sensitive information into an AI tool unless the organization has explicitly approved that tool and that specific use. Screenshots containing sensitive data follow the same rule.

Frame 05

Two Sets, Not One

"AI tool" is not automatically equivalent to "company-approved AI tool." A public street set and a controlled studio backlot can look similar from a distance — the difference is everything happening off-camera.

The Public Street Set

Any consumer AI tool
  • Security controls — unknown
  • Data handling — unclear
  • Retention practices — unclear
  • Access controls — unmanaged
  • Privacy protections — unverified
  • Enterprise configuration — none
  • Administrative oversight — none

The Studio Backlot

Company-approved AI environment
  • Security controls — defined
  • Data handling — governed
  • Retention practices — set by policy
  • Access controls — managed
  • Privacy protections — verified
  • Enterprise configuration — in place
  • Administrative oversight — active

Use only the AI tools approved by your organization for work-related information. When in doubt, ask your supervisor, security team, privacy team, or designated AI governance contact.

Frame 06

The STOP Test

Before anything goes into AI, run the red flag test. Tap each cue card to flip it face-up.

SSensitive? Does it contain personal, confidential, or restricted data?
TTool approved? Is this AI tool explicitly approved for work use?
OOnly necessary? Am I providing more information than the task requires?
PPolicy checked? Does the use comply with company policy?
